# Gym Calculator 🏋️

A barbell plate calculator with a visual GUI, built in Python with Tkinter.

## What it does
- Calculates the optimal plates to load on each side of the bar for any target weight
- Draws the loaded barbell visually with standard gym plate colors
- Supports lbs and kg, with one-click unit conversion
- Multiple bar types (Standard Olympic, Women's Olympic, Training Bar)
- Save and load your lifts to a JSON file

## How to run
1. Make sure Python 3 is installed
2. Download `GymCalculator.py`
3. Run: `python3 GymCalculator.py`

## Built with
- Python 3
- Tkinter (GUI)
- JSON (saving lifts)
